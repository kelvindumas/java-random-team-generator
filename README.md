# Java Random Team Generator

Originally named Collections-NumbsHomework.

## Project Overview

This project was developed as part of my studies in Computing Science and IT at CCT College Dublin.

The objective of this project was to build a Java console application that reads a list of people from a CSV file, shuffles them randomly and distributes them into 20 teams of 5 members each. Every team is named after a fruit, and the final teams are printed to the console.

The project focuses on working with collections, reading data from files and modelling data with simple classes. In NetBeans the project is called CollectionsAndEnumsHomework.

## Project Objectives

The main objectives of this project were:

- To read structured data from a CSV file using BufferedReader and FileReader
- To model data with classes (Person and Team)
- To store and manipulate data with List and ArrayList
- To shuffle a list randomly with Collections.shuffle
- To customise the text output of objects by overriding toString
- To handle file errors with try-with-resources and exception handling

## System Architecture

All classes live in the package collectionsandenumshomework:

- CollectionsAndEnumsHomework - main class, with the methods readDataFromFile and createTeams
- Person - stores the id, first name, last name and email of one person
- Team - stores the name of a team and the list of its members

## How It Works

1. The program reads MOCK_DATA.csv line by line.
2. Each valid line (id, first name, last name, email) becomes a Person object.
3. The list of people is shuffled with a Random generator seeded with the current time, so the result is different on every run.
4. Twenty teams are created, each one taking 5 people from the shuffled list.
5. Each team is printed with its name and its members.

The 20 team names are: Strawberry, Pear, Pineapple, Cherry, Banana, Lemon, Mango, Blackberry, Pomegranate, Apple, Kiwi, Passion Fruit, Melon, Raspberry, Watermelon, Coconut, Orange, Grape, Lime and Peach.

Output format (the people in each team change on every run):

```
Team: Team Strawberry
 Firstname Lastname (email@example.com)
 Firstname Lastname (email@example.com)
 Firstname Lastname (email@example.com)
 Firstname Lastname (email@example.com)
 Firstname Lastname (email@example.com)

Team: Team Pear
 ...
```

## Data

MOCK_DATA.csv contains 100 rows of mock sample data in the format id, first name, last name, email. The file must be in the working directory when the program runs, which is the root of the repository when it is started from NetBeans or from the command line as shown below.

## Technologies Used

- Java (the NetBeans project uses source level 20)
- Apache NetBeans (Ant-based project)
- java.io: BufferedReader, FileReader and IOException
- java.util: List, ArrayList, Collections and Random

## System Limitations

- The file name MOCK_DATA.csv is written directly inside readDataFromFile, so the fileName parameter is not used
- The program needs at least 100 valid records (20 teams of 5 people), otherwise it fails when the list runs out
- Lines that do not have exactly 4 comma-separated fields are skipped without any message
- The team names are stored in a plain String array, not in an enum
- The shuffle is not reproducible, because it is seeded with the current time

## Possible Future Improvements

- Use an enum for the team names
- Let the user choose the number of teams and the team size
- Receive the CSV path as a command-line argument
- Report invalid rows instead of skipping them silently
- Export the teams to a file

## Learning Outcomes

This project demonstrates important concepts in Java development, including:

- file input with BufferedReader
- collections and list manipulation
- random shuffling of data
- object modelling with simple classes
- overriding toString for readable output
- exception handling with try-with-resources

## Repository Structure

- src/collectionsandenumshomework - CollectionsAndEnumsHomework.java, Person.java, Team.java and a copy of MOCK_DATA.csv
- MOCK_DATA.csv - sample data read by the program
- build/ - compiled classes generated by NetBeans
- nbproject/, build.xml and manifest.mf - NetBeans / Ant project files

## How to Run

Open the project in NetBeans and run it, or compile and run it from the root of the repository, where MOCK_DATA.csv is located:

```
javac -d out src/collectionsandenumshomework/*.java
java -cp out collectionsandenumshomework.CollectionsAndEnumsHomework
```

## Conclusion

This is a small Java application that turns a CSV file into randomly assigned teams. It is a practical exercise in file reading, collections and simple object modelling.
